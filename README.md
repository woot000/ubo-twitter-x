# woot000's Twitter/X uBlock Origin Filters

A set of filters for [uBlock Origin](https://github.com/gorhill/uBlock) which makes Twitter/X mildly more usable by reducing some visual clutter, removing unnecessary buttons and hiding superfluous advertisements.

## Install

### Automatic (add to filter lists)

Copy [this link](https://raw.githubusercontent.com/woot000/ubo-twitter-x/refs/heads/main/twitter-x.txt) to the clipboard. Then, navigate to `uBlock Origin` > `Open the dashboard` > `Filter lists`, scroll down to `Import`, paste the link and click on `Apply changes`.

This option provides automatic updates (assuming `Auto-update filter lists` is checked on the top), but you can't edit the individual filters.

### Manual (Copy and paste)

Click on [`twitter-x.txt`](twitter-x.txt) and save it to your desktop. Then, navigate to `uBlock Origin` > `Open the dashboard` > `My filters`, click on `Import and append...`, and open `twitter-x.txt`. The filters should appear in the filter box, appended at the bottom if any other filters were there before.

This option provides the ability to edit the individual filters (like putting a `!` before a filter to disable it and vice versa), but requires you to repeat this process in order to update the filters.
